# VRMアバター（表情・体で動く）

カメラに映った顔と上半身の動きで、VRMモデルの表情・頭・体・腕を動かす Web アプリです。
グリーンバックなどの単色背景の「出力画面」を別ウィンドウで開き、ATEM などに送れます。
サーバー側の処理はありません。静的ファイルを置くだけで動きます（GitHub Pages・さくらサーバ可）。

## 置き方
- このフォルダの中身をそのまま公開します（例：GitHub の `avatar5` リポジトリ → https://ehayaoka.github.io/avatar5/ ）。
- カメラを使うため、**https:// のURL** から開いてください（ファイルを直接開くと動きません）。
- `samples/lily_hat.vrm` は「サンプル」ボタンと初回起動で読み込むモデルです（約22MB）。不要なら削除し、`js/app.js` の `samples/lily_hat.vrm` を別のモデル名に変えてください。
  モデル情報：名前 lily5、作者 hayaoka、再配布可（VRM 1.0 ライセンス）。

## 使い方
1. Chrome または Edge（Safari も可）で開く。初回はサンプルのモデルが表示される。
2. 自分の VRM を使うときは［VRMファイルを選ぶ］か、プレビューに .vrm をドラッグ。
3. ［▶ カメラ開始］→ カメラを許可 → 正面を向いて力を抜き［いつもの顔を登録］（3秒後に記録）。
4. 下のガイドを見ながら、目・口・眉・頭・体・腕を動かす。✓ が付いた行がキャラクターに反映されている動き。
5. ［出力画面を開く］→ 出力用ウィンドウを ATEM につながったディスプレイへ移動し、ダブルクリックで全画面。

## 操作
| 操作 | 内容 |
|---|---|
| プレビューを左ドラッグ | モデルを回り込んで見る |
| 右ドラッグ／Shift＋ドラッグ | 位置をずらす |
| ホイール／トラックパッドのピンチ | ズーム |
| ［顔］［上半身］［全身］ | 構図をすぐに切り替え |
| 体の向き | モデル自体の向きを変える |
| 背景色 | 緑・青・マゼンタ・白、ほかの色も選べる（出力画面も同じ色） |
| キー `0`〜`5` | 0：自動、1〜5：表情を固定（通常・喜び・怒り・困り・驚き） |
| キー `F` / `H` / `M` | 全画面 / 設定を隠す / カメラとガイドの表示 |

## 動きの対応
| 人の動き | キャラクター（VRM の表情・骨） |
|---|---|
| 目を閉じる | blink（「ウインク」をオンにすると blinkLeft / blinkRight） |
| 口を開ける・すぼめる | aa・ou（oh も少し） |
| 口角を上げる | happy |
| 眉を寄せる | angry |
| 眉頭だけ上げる | sad（困り） |
| 目を見開く・眉を上げる | surprised |
| 目だけ動かす | 目線（lookAt） |
| 顔を左右・上下に向ける、首をかしげる | 首・頭 |
| 体を傾ける・ひねる | 背骨・胸（肩が映っていれば肩の線から、映っていなければ顔の位置から） |
| 手を上げる | 腕（ひじがカメラに映ったときだけ。映っていないときは下ろした形） |

## 注意
- 顔・体の判定には MediaPipe（Google）を使い、すべてブラウザの中で処理します。カメラ映像やVRMファイルはどこにも送信されません。VRMはブラウザ内（IndexedDB）に保存されます。
- 操作画面と出力画面の両方でモデルを描くため、古いパソコンでは動きが重くなることがあります。その場合は出力画面のウィンドウを小さくするか、モデルの軽い VRM を使ってください。
- 腕の動きは単眼カメラからの推定です。正面から少し離れ、肩からひじまで映るようにすると安定します。指の動きには対応していません。
- 使用ライブラリ：three.js（MIT）、@pixiv/three-vrm（MIT）、MediaPipe Tasks Vision（Apache 2.0）。各 LICENSE は `vendor/` にあります。
